# Geographic renderer

MapLibre GL JS/CSS 5.6.0 downloaded from https://unpkg.com/maplibre-gl@5.6.0/dist/; license bundled as MapLibre-LICENSE.txt. No runtime CDN script dependency. Custom map.html is Hermi frontend code.

Vector tiles: https://tiles.openfreemap.org/planet, following https://openfreemap.org/quick_start/. Provider/source attribution remains visible and links open externally. The map uses real coordinates, public tiles and a custom restrained pixel style. No API key, account data, device location or Hermi backend calls. Tile network failure shows Retry; last product draft remains in Swift state. Network/cache/offline production behavior is not accepted yet.
